# Resources

This file provides information and resources that supplement the new code content included here.

## Introduction

The EEK (ESP32 by Example Kit) hardware developed from a concept aimed to fly a real Tello drone [Tello](https://www.ryzerobotics.com/tello). This drone is no longer available except as a refurb model.

With the help of Peter Dalmaris, the EEK concept was re-directed to education: learning the ESP32 and programming Cyber-Physical Systems. 

## IoTinUrHand site

Before my association with Elektor led to the creation and marketing of the EEK Academy Pro box I created hardware and software as a sole developer and created a bespoke website for this work: [IotInUrHand](https://iotinurhand.com). The links at the site are worth exploring including early videos of EEK BreadBoard assembly.

At this site is a link to my storefront where early versions of the EEK Hardware were sold: [IoTinUrHand Store](https://shop.iotinurhand.store/). The store front is still active.

## Older GitHub Repositories

Before the production of this GitHub project, I worked on other projects: [Older Repos](https://github.com/jsolderitsch?tab=repositories). 

Of particular interest is the project for the EEK itself: [EEK GitHub](https://github.com/jsolderitsch/ESP32ByExample). This project was enhanced when the EEK Academy Pro box was published. Gerber files for the PCB version of the EEK are available there as well as many EEK examples.

## YouTube Playlists

I have had a YouTube channel for a number of years but not promoted it. To support the recent Elektor Magazine interview conducted on August 26, 2026 I created several video playlists. Some of the videos in the playlists were created in support of my classes at Villanova University.

[EEK and AI](https://www.youtube.com/playlist?list=PLe2bv8bOXaoE)

The first video in the list shows EEK example generation with the free Claude App. Other videos show other kinds of AI-assisted EEK control actions.

[EEK and Cheap Yellow Display](https://www.youtube.com/playlist?list=PLOD_5INM3avo)

Before the planned switch to the StackChan as a device to control, and after the creation of a custom BreadBoard for a Drone Simulator, the CYD: Cheap Yellow Display was the main target for EEK Cyber-Physical control. The CYD is included in the EEK Academy Pro box. The videos in this list show the EEK controlling the CYD in various ways.

[EEK Summer 2026](https://www.youtube.com/playlist?list=PLSzr7Cu-rSQA)

In conjunction with the recent creation of this GitHub project, I have begun to create a new series of videos. The first three of these are included (as of August 26) in the playlist with more of them to follow.
